# Attribution & Sources

This dataset is an **index**, not a mirror. It records the facts we've verified about
each board game and each 3D-printable design we've found for it, plus a link back to
the original listing — never a copy of a listing's own description or images. If you
want the full listing (photos, write-up, files to download), follow the `url` field to
the original platform.

## Board game data

Sourced from **[BoardGameGeek](https://boardgamegeek.com)** (name, year, BGG ID, and
the game's canonical BGG page). BGG is the authoritative source for this data — please
consult BGG's own terms before any bulk reuse of data derived from their site.

> **Before pushing new data derived from BGG**: read BoardGameGeek's current XML API
> terms of use (and geeklist/community-content terms, if geeklist-derived data is ever
> included here) end to end. This dataset's game data traces back to BGG throughout, so
> this is the single most important thing to actually verify — not just assume.

## 3D print listings

Print titles, engagement stats (likes, downloads, etc.), and outbound links are sourced
from, and belong to their original creators on:

- [Printables](https://www.printables.com) (Prusa Research)
- [MakerWorld](https://makerworld.com) (Bambu Lab)
- [Thingiverse](https://www.thingiverse.com) (MakerBot)
- [Cults3D](https://cults3d.com)

Discovery for a portion of this catalog was assisted by
**[3dsearch.net](https://3dsearch.net)**, an aggregator of the above platforms.

**No descriptions, images, or 3D model files from any of these platforms are
reproduced here.** Every print record is a pointer (title + link + basic public
engagement numbers) back to where the actual design lives.

## Removal requests

If you're a creator (or represent a platform) and want an entry removed from this
dataset, [open an issue](../../issues) — we'll remove it promptly, no questions asked.
